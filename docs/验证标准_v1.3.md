# 验证标准 v1.3（2026-10-12 升版）

> **v1.3 取代 v1.2**，只加一条**数值书写归一**；v1 / v1.1 / v1.2 原文与结果原样保留。
> 触发原因：全量回归时发现**真实模型输出的书写形式**被当成数据断言，
> 导致正确结论被判不可信（主集支持率 0.7273）。

## 一、改动：同一个数的不同写法先归一，再判定

| 写法 | 例子 | 归一则 |
|---|---|---|
| 千分位 | `1,070,704.67` | 去掉分隔符后按一个数比较（此前被拆成 `1`/`070`/`704.67`） |
| 单位后缀 | `974.77 万` | v1.2 已做：文本与声明值按同一系数归一 |
| 裸月份 / 日 | `11月为 1461756.25`、`12月9日` | 时间指代，不做数据断言 |
| 步骤引用 | `步骤2 中…`、`step3` | 跳过（结论**被要求**引用步骤编号） |
| 描述里的短日期 | `reverse 21/5/10 adjustment` | 日期串，跳过 |

判定主干不变：V1 数值一致性 / V2 证据覆盖 / V3 结果充分性 / V4 解释强度越界。
归一只是**把同一个值换一种写法的干扰去掉**，不放松"必须落到证据上"这一步。

## 二、没被放松的边界（单元测试守着）

- 编造编号（结果里没有）→ 仍判"没有声明来源"；
- 编码参与比较时，比较出来的数字（如"高 20%"）→ 仍必须可核对；
- 无来源的「约 100 万」、单位写错的「974.77 千」→ 仍判不支持；
- 千分位写法的数字**没在证据里**时照样判"与声明的来源步骤对不上"。

## 三、效果（同一批输出做反事实，隔离模型波动）

| 口径 | 结论条数 | 被支持 | 支持率 |
|---|---|---|---|
| v1.2 当时判定 | 55 | 40 | 0.7273 |
| 同批输出的反事实（书写类问题不计） | 55 | 50 | **0.9091** |
| v1.3 重跑（另一批输出） | 53 | 48 | **0.9057** |

拦截问题构成：v1.2 主集 87 个问题里，**千分位碎片 60 + 裸月份 20**，真实核对失败 7；
v1.3 主集 9 个问题**全部**是真实核对失败。详见 `docs/回归报告_v1.3.md`。

## 五、限制

1. **冻结集测不到书写多样性**：holdout 由生成器按规范格式生成，本轮暴露的千分位、
   裸月份等问题它一条都没抓到——以后改判定规则，必须同时跑冻结集与真实输出；
2. 归一规则是**枚举式**的（千分位 / 月份 / 步骤 / 短日期 / 单位），
   新增书写变体（全角逗号、其它量词等）仍可能误拦；
3. 剩余的书写变体与别名表都不并入本版，登记为 v1.4 候选。
