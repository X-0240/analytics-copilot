# 验证标准 v1（2026-10-11 冻结）

> 冻结时点：**2026-10-11**，冻结发生在跑 holdout **之前**。
> 冻结范围：支持规则、阈值、caveat 规则、降级/拒答规则。
> 冻结后不得为得到好看的数字调整这些规则；确需修改须**升版本**，并把旧结果标 `INVALIDATED`。

## 一、支持规则（V1/V2，决定一条结论是否被证据支持）

一条 claim 被判**支持**，必须同时满足：

1. **数字有来源**：claim 文本里的"数据断言数字"都能在 `numbers[]` 里找到声明；
2. **来源可核对**：`numbers[]` 里声明的值能在其 `step` 的结果里匹配到；
3. **维度可核对**：`dimension_values[]` 里点名的维度值出现在结果里（含中英别名表）。

### 什么不算"数据断言数字"（剔除以避免误拦）

- 日期：`YYYY-MM`、`YYYY年M月`、`YYYY/MM`；
- 带前缀的标识：`商品/SKU/货号/编号/客户/invoice + 字母数字`；
- 裸字母数字混合标识：含字母且长度 ≥4 的 token（如 `85123A`）；
- 排名词：`前 N`、`第 N`。

**已知限制**：纯数字编号（如 `23843`）只有在带上述前缀时才被剔除。

## 二、阈值

| 项 | 阈值 | 说明 |
|---|---|---|
| 数值匹配 | 绝对差 ≤ 0.01，或相对差 ≤ 2%，或**绝对值相等** | 绝对值放宽是有意取舍：退货金额在数据里为负，结论常写绝对值；代价是漏掉"正负号写反" |
| 维度值匹配 | 字符串包含（大小写不敏感）+ 中英别名表（12 个常用国家） | 表外国家会误判为 V2 失败，属已知限制 |
| 步数上限 | 4 | 超出即计划不合法 |
| SQL 超时 / 行数上限 | 8 秒，可通过配置覆盖 / 500 行 | 由数据层护栏负责 |
| 澄清轮数 | 2 轮 | 超过则带显式假设继续 |

## 三、V3 结果充分性（只降级，不拦截）

触发条件（任一）：

1. 问题含归因词（为什么 / 原因 / 导致 / 归因 / 贡献）
   **且** 计划里只涉及 1 个维度 **且** 无时间序列；
2. 任一执行步骤返回 0 行。

触发后果：**加 caveat + 置信度降为 low**，结论本身保留。

## 四、降级与拒答规则（整体行为）

| 情形 | 行为 | 状态值 |
|---|---|---|
| 所有 claim 都被 V1/V2 拦下 | 不输出强结论，只报证据与不确定性 | `unsupported` |
| 计划两次都无法通过护栏 | 结构化说明"做不到 + 原因" | `unable_to_complete` |
| 问题超出能力边界（预测 / 因果 / 无成本字段的利润） | 明确拒答并给原因 | `refused` |
| 缺少必要信息（指标 / 比较维度） | 先澄清，最多 2 轮 | `need_clarification` |
