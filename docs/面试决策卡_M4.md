# 面试决策卡 · M4（holdout + 解释强度模型 v1.1）

## 决策 1：为什么要把"为什么"分级，而不是继续拒答？

拒答"为什么销售额下降"在技术上安全，在产品上无用——业务人员的日常提问就是"为什么"。
但他要的通常不是因果证明，而是"哪些因素在同步变化"。所以把输出拆成三级：
Level 1 事实、Level 2 相关性解释、Level 3 因果结论（**本项目禁止输出**）。
代价：系统不再能用"拒答"回避边界，必须自己说清"我能说到哪一级"。

## 决策 2：等级由谁定，模型自述还是机械算？

**机械算**（`explain.evidence_level`）：计划里有没有可比较维度、有没有时间序列、
有没有真的取到行——三条都由代码判定，模型不能给自己抬级。
只有"因果措辞检测"是文本匹配，靠词表（导致/造成/因为/由于/根本原因…）。

## 决策 3：结论越级了怎么办，改写还是降级？

**不改写**，只降置信度 + 追加固定边界措辞，并把 V4 违规记进 trace。
理由跟 M2 的 V3 一致：改写等于让系统替模型说话，事后无法追责；
保留原句 + 显式标注，才能让"模型写了什么"和"系统认不认"分开审计。

## 决策 4：因果类提问走兜底，是不是等于把 LLM 降级成规则？

只有**这一条路径**用规则兜底：模型判"这是因果问题→拒答"且理由含因果词时，
改用确定性计划取数，结论写成"本次只做事实与相关变化描述：最大维度是 X（值 Y）"。
实测两轮里模型对因果题会稳定拒答，再追问是白烧调用；
代价是兜底结论只有 1 条、信息量低于正常作答——这是明知的取舍，不是能力上限。

## 决策 5：这一版最该讲的一个数字是哪个？

**因果类拒答 2 → 0（主集 T-302 + 边界 T-401），同时"强因果声明"仍是 0。**
前一半说明产品可用性变了，后一半说明放开边界后**没有**换来幻觉
——22 题里出现的唯一一条因果措辞（"主要由退货造成"）被 V4 拦下并降级。
诚实提醒：两臂是两次不同运行，除规则直接决定的部分外，其余差值都在噪声范围内。

## 决策 6：holdout 上测出误拦 42.9%，为什么当时不改规则？

因为规则是**跑之前冻结的**，看到难样本再改，就等于让 holdout 变成调参集。
正确做法是登记三条归因（别名表外国家 / 单位换算 / 裸数字编号）留给 v1.2。
面试可以反过来用：这说明判据本身需要被当作被测对象，而不是当成真理。
