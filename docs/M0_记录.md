## 二、技术选择及理由

| 选择 | 理由 |
|---|---|
| DuckDB 作分析执行层 | 列存、面向分析型聚合、单文件、无独立服务 → 便于容器化与单实例部署；本任务全是聚合查询，DuckDB 的内存列存比行存快得多 |
| 只读连接 + 对象白名单 + 单语句 + 行数上限 | 四层一起才有意义：SQL 检查可能被绕过，物理只读是兜底；行数上限防止一次拉全表 |
| 只暴露视图、不暴露原始表 | 原始表没有口径列（`is_return`、`line_revenue`），直接暴露会诱导错误口径；视图把口径固定下来 |
| 任务理解用**状态谓词**而不是分类器 | 冻结稿明确"不做固定分类 workflow"；谓词只回答"缺什么"，可机械测试，不需要训练数据 |
| 结果检查优先机械可判 | 项目一实测两个模型评分者一致率仅 4/10 → LLM judge 不作主判，只作补充 |
| 服务层用 FastAPI + 单接口 | 为 M5 公网部署留接口边界；单一 `/ask` 便于日志、超时、错误码统一处理 |

## 三、替代方案与为什么不用

| 替代 | 为什么不用 |
|---|---|
| MySQL / PostgreSQL | 需要独立服务与运维；分析型聚合在行存上慢；M0 无并发需求，用不上 |
| SQLite | 部署最轻，但列存缺失，几十万行的多维聚合明显慢于 DuckDB |
| pandas 直接算 | 无法承载"只读 SQL 工具面"，也不便于把查询当证据留痕 |
| DuckDB excel 扩展直读 xlsx | 需要联网下载扩展，本机代理下 HTTP 302 失败（见踩坑 1） |
| LLM 生成计划（M0 就上） | 先要验证链路与护栏是否成立；桩能把链路、证据链、错误码全部测到，接模型时只换实现 |
| Redis / 外部会话存储 | 属"为展示复杂架构引入无必要组件"（负责人明确禁止）；单实例内存态够用，限制已如实写明 |
| 多 Agent / supervisor | 项目三已实测：token 2.79×、延迟 P95 1.98×、20 条配对 1 改善 0 退化 19 相同、无可追溯增益 |

## 四、面试可能追问点（含回答要点）

1. **为什么不用 MySQL？** → 分析型聚合 + 单文件 + 无服务依赖；配合容器化单实例部署最省。
2. **怎么保证 SQL 安全？** → 四层：白名单对象、单语句、禁止写关键字、物理只读连接；再加行数上限。**没做权限体系**（明确不做）。
3. **超时怎么实现的？真的能中断查询吗？** → 请求级 `asyncio` 超时；**DuckDB 查询不会真正中断**，靠白名单 + 行数上限 + 视图预聚合限制扫描面。这是已知限制，写在 README。
4. **你的"验证层"在哪？** → M0 只有两道机械检查（fan-out、占比合计）；完整验证层在 M2，且 LLM judge 不作主判。
5. **会话放内存，多实例怎么办？** → 单实例设计（M5 也是单实例）；多实例要换存储，属不做范围。
6. **第一条结论 84% 占比说明什么？** → UK 占绝大多数，跨国比较必须报占比；口径已写进 metadata。

## 五、踩坑与失败方案（真实记录）

1. **DuckDB excel 扩展装不上**：`INSTALL excel` 需联网下载扩展，本机代理下返回 HTTP 302，
   且失败要等约 5 分钟。→ 改路由：openpyxl 流式转 CSV（约 68 秒，一次）→ `read_csv_auto`
   （重建 2.2 秒）；扩展尝试改成 `--try-excel-ext` 显式开启。
2. **`CREATE TABLE AS SELECT ... AS <同名列>` 报错**："Column referenced that exists in the
   SELECT clause but cannot be referenced before it is defined"。→ 改成读 CSV 时用 `types=`
   显式声明类型，并把 CSV 列名（`invoiceno` 等）在用别名时改名。
3. **`SHOW TABLES` 只返回一列**，按两列取值直接 IndexError。→ 改用 `information_schema.tables`。
4. **遍历 dict 列表时 `for name, _kind in tables`** 解包成键名，`DESCRIBE name` 被 DuckDB
   当成替换扫描，报"Python Object 'name' ... not suitable for replacement scans"。→ 按键取值 + 给标识符加双引号。
5. **占比检查与 LIMIT 冲突**：维度贡献查询原来带 `LIMIT 10`，占比合计必然 <1，检查误报。
   → 去掉 LIMIT（行数上限由工具层兜），并在结果被截断时跳过该检查。
